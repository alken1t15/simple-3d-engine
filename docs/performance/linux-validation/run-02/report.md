## Ограничения и ручное наблюдение

Среднее время кадра = длительность / число показанных кадров, не GPU timestamp. Max callback gap — интервал между опросами приложения с обработкой событий/рендером/swap/инструментированием, не точный frame time: refresh может показать несколько кадров без callback. Субсекундные просадки локализуются только до интервала наблюдения; p95/p99 и точная длительность отдельных зависаний не вычисляются. Запись файлов и JSON — после Run, память опрашивается примерно раз в секунду; стоимость опроса входит в замер.

- Визуальные просадки: **заполнить оператору** — где, как долго приблизительно, разовые/повторяющиеся; сопоставить с интервалами, не объявлять средний FPS доказательством плавности
- Тренд памяти по полному ряду: **заполнить оператору** — плато/колебания/рост/падение; численного порога утечки не задано
- GPU-кэш: **приложить результат** отдельного performance-cache-smoke для этой сцены (1 GPU mesh и 1 GPU texture после показа; 0 после Dispose); данный FPS-прогон внутренние GPU handles не читает
- Условия стенда: **дополнить** CPU/RAM/GPU/драйвер, SDK/OpenTK, дисплей/частота/масштаб, питание/профиль, фоновые процессы, версия исходников, #13 smoke; фактическое ограничение VSync драйвером отдельно от запрошенного
