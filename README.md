# Simple 3D Engine

Учебный проект: небольшой **3D-графический движок на C#** с публичным API. Сейчас репозиторий находится на **этапе планирования**: требования, архитектура и порядок разработки готовы, реализация движка еще не начиналась.

## Что планируется

- Сцена с несколькими объектами, камерой и преобразованиями `position / rotation / scale`.
- Простая полигональная геометрия: индексные треугольники, куб и плоскость.
- Отрисовка с корректной глубиной, базовым материалом и одной текстурой по UV.
- Отдельное демо, которое использует публичный API без прямых вызовов OpenGL.
- Нагрузочная сцена примерно из 1000 простых объектов с воспроизводимым замером FPS.

Игровая логика, физика, коллизии и редактор сцен не входят в базовый объем. Точный статус каждого требования и граница MVP записаны в [плане](project_plan.md).

## Участие

До параллельной разработки зафиксировать формат данных и жизненный цикл API; далее работать через небольшие задачи и pull request. Правила ревью и проверок — в [процессе разработки](docs/development-process.md). Публичные изменения в API должны сохранять два сценария из [требований](docs/requirements.md).
